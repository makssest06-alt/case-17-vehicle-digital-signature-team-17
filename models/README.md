# Модели (веса)

Папка для весов ReID-моделей команды 17. Бинарники хранятся через Git LFS
(нужен `git lfs install` перед клонированием, иначе скачается указатель).

## Production-модель: `reid_current.pt` = `siglip_vitb16_reid_geom_ep30.pt`

Оба файла — одни и те же веса (LFS хранит их одним объектом):

* `reid_current.pt` — имя по умолчанию, которое читает сервис
  (`REID_WEIGHTS`), поэтому он подхватывается без настройки;
* `siglip_vitb16_reid_geom_ep30.pt` — понятное имя для человека и трассировки.

**Что это.** Полностью дообученный (не только голова) экстрактор цифрового
признака ТС: SigLIP ViT-B/16 + ReID-голова с BNNeck.

**Архитектура.**

| Часть | Значение |
|---|---|
| Бэкбон | `vit_base_patch16_siglip_224.webli` (timm), dim 768 |
| Голова | `ReidHead`: 768 → 1024 → 512, BNNeck, dropout 0.3 |
| Лоссы | ArcFace (margin) + batch-hard Triplet (margin 0.3) |
| Сэмплер | PK: P=8, K=4 |
| Выход | L2-нормированный вектор, 512D |
| Для инференса | ветка после BNNeck (`feat_bn`), усреднение с отражением |

**Обучение.** Полное дообучение бэкбона на train-сплите (1 391 машина,
8 644 кадра), 30 эпох, RTX 4060 Laptop 8 ГБ, ~2 ч 38 мин. Кроп по BBox с
запасом 10% с каждой стороны (совпадает с production `api/app/imaging.py`,
`BBOX_PAD=0.10`), вход 224×224.

**Аугментации** (ключевое отличие от предыдущей версии): геометрические —
перспектива, part-crop (RandomResizedCrop), поворот ±7°; фотометрические —
ночь, блики, смаз, JPEG, отражение, random erasing.

**Качество** (cross-camera валидация: 551 query, 361 gallery, кандидаты с той
же камерой исключаются; flip-TTA, как в production):

| Метрика | Значение |
|---|---:|
| mAP | **76.74** |
| Rank-1 | **72.05** |
| Rank-5 | **88.38** |

**История улучшений** (тот же сплит):

| Модель | mAP | Rank-1 | Rank-5 |
|---|---:|---:|---:|
| CLIP ViT-B/16 zero-shot | 19.52 | 15.61 | - |
| SigLIP zero-shot | 46.14 | 41.02 | 63.70 |
| SigLIP + обученная голова | 65.16 | 60.44 | 79.85 |
| SigLIP, полное дообучение (ep29, без геом.) | 74.38 | 69.15 | 88.02 |
| **SigLIP, полное дообучение + геом. (ep30)** | **76.74** | **72.05** | **88.38** |

Геометрические аугментации дали **+2.36 mAP** и **+2.9 Rank-1**. Катастрофических
провалов (правильный ответ дальше 50-го места) стало **5 против 13**.

**Формат чекпоинта.** `torch.save({"model": …, "margin": …, "args": {…}})`;
верхнеуровневые ключи `['args','margin','model']`, в `model` — 176 тензоров
(`encoder.*` и `head.*`). Читается без правок кодом сервиса
`api/app/models/reid_checkpoint.py`.

**Как включить в сервисе.**

```bash
EMBED_MODEL=reid:vit_base_patch16_siglip_224.webli
REID_WEIGHTS=/models/reid_current.pt
```

Проверено (`research/verify_production.py`): те же веса, загруженные кодом
сервиса и посчитанные его же `embed_batch`, дают на том же сплите ровно те же
метрики — mAP 76.74, Rank-1 72.05, Rank-5 88.38.

**Лицензия.** Бэкбон Apache 2.0 (Google SigLIP); обучающие данные — внутренние
(WebLI не публикуется), что допустимо по условиям кейса.

## Как добавить новую модель

1. Положить файл `*.pt` в эту папку с понятным именем
   (`<бэкбон>_<тег>_ep<N>.pt`).
2. Если это новая production-модель — скопировать её в `reid_current.pt`.
3. Дописать сюда раздел: что это, архитектура, метрики, как включается.
4. Закоммитить (LFS подхватит `*.pt` автоматически).
