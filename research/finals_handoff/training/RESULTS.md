# Sub-center ArcFace experiment — candidate rejected

## Exact experiment

- Teacher embeddings: existing train-only 4-model teacher `(8644,512)`, matched
  8644 train rows and 1391 train identities. No test image or label was used.
- Candidate: SigLIP2 ViT-B/16, same init, alpha=25, ArcFace scale=30/margin=.25,
  batch-hard triplet margin=.3, P=8/K=4 cross-camera sampler, same augmentations,
  seed=7, 30 epochs; two ArcFace centers per identity. Only epoch 28 retained.
- Training: RTX 4060, CUDA AMP, 5190 optimizer steps, 2473 seconds, no OOM.
- Candidate checkpoint size 382,584,947 bytes (~365 MiB); SHA-256
  `9e130fb3431402939699d17079ff24f7128ffd4a991998bc3df178dd1d5abe96`.
  The binary stays on the local experiment disk and is intentionally not copied
  to this handoff branch because the candidate fails the fixed acceptance test.

## Validation protocol

Same 150-ID holdout split (551 query / 361 gallery) and official evaluator copied
from organizer `evaluate.py`. Ranking uses raw cosine only; `submission.csv`
contains the top 10 cosine IDs. The official evaluator then removes junk
(same vehicle AND same camera) from those submitted IDs and does not backfill
the removed slots. No reranker or parameter tuning is used. This reproduces
the evaluator behavior on the artifact format, rather than an independently
re-ranked full-gallery list.
The baseline embeddings and candidate embeddings were both generated by the same
`extract_emb.py`, squash transform, bbox padding 0.10, no TTA.

| Metric | Baseline student | Sub-center candidate | Delta |
|---|---:|---:|---:|
| mAP@10 | 0.857729 | 0.838624 | -0.019105 |
| Rank-1 | 0.822142 | 0.803993 | -0.018149 |
| Rank-5 | 0.923775 | 0.927405 | +0.003630 |

The copied evaluator at `official_evaluate.py` is identical to both local official
copies (SHA-256 `655c71db8c2e4d2cd7680c40c768afacfdffff360401111c1a46df921551ffa3`).
`evaluate_pair.py` writes exactly 10 unique IDs per query; evaluator removes junk
from those submitted 10 without backfilling. It does not rank the entire gallery
then refill top-10 after removing junk.

Result: **reject candidate, retain existing `siglip2_distill_ensemble_ep28.pt`.**
Sub-center improves Rank-5 slightly but substantially hurts mAP@10 and Rank-1.
No ensemble fusion was attempted; one-model memory constraint remains respected.

## Reproduction

Head tests:

```bash
python -m unittest research.finals_handoff.training.test_subcenter -v
```

Training command (paths here are from the originating local research environment):

```bash
python research/finals_handoff/training/train_distill.py \
  --backbone siglip2_base \
  --init-from <MODELS>/improve_models/siglip2_init.pt \
  --teacher <MODELS>/improve_models/teacher_emb.npy \
  --rows-csv <MODELS>/improve_models/distill_train_rows.csv \
  --images-dir <DATA>/images \
  --models-dir <MODELS>/models \
  --tag siglip2_distill_subcenter_k2 --alpha 25 --epochs 30 \
  --lr-head 3e-4 --lr-backbone 1e-5 --wd 5e-4 --P 8 --K 4 \
  --warmup 3 --context 0.10 --seed 7 --amp --subcenters 2 --save-epochs 28
```

The `improve_models/` teacher and source data are local and not committed. Paths
must be remapped to the user's workspace to reproduce. Their SHA-256 hashes,
plus baseline weights/embeddings and evaluator hash, are in `experiment.json`.
The training rows contain only train split IDs; the validation split is separate.

Candidate extraction command:

```bash
python analysis/extract_emb.py \
  --ckpt models/siglip2_distill_subcenter_k2_ep28.pt \
  --tag subcenter_k2_ep28 --tf-mode squash \
  --images-dir /path/to/dataset_extracted/images \
  --val-csv /path/to/research/ensemble/val_split.csv \
  --boxes-csv /path/to/dataset_extracted/train.csv \
  --context 0.10 --bs 32 --out-dir /path/to/val_embeddings
```

Checkpoint args record `tf_mode=squash` and `input_size=224`; extractor defaults
to checkpoint transform and errors if a conflicting transform is specified.
