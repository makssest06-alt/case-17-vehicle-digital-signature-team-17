# Официальный bench — RTX 4060 Laptop, glebmain e41f92a (PR#5 слит)

Запуск: `api/scripts/bench_extract.py` (официальный, слит PR#5), полный цикл `app/extractor.py:extract()`.
Код официальный (не суррогат); **контейнерный путь недоступен на машине** — нет прав sudo на установку
nvidia-container-toolkit (`docker run --gpus all fail: "could not select device driver"). Запущен
нативно тем же скриптом/кодом; в контейнере повторить при наличии sudo — команда в README §3.

Окружение: RTX 4060 Laptop 8GB, CUDA 13.2, torch 2.14.1+cu130 (нативно), fp16 активен.
Данные: локальный расчленённый датасет организаторов, test_query.csv (1110 строк, цикл по первым 256).
Дефолты скрипта: REID_FP16=1, EXTRACT_JPEG_DRAFT=0, EXTRACT_THREADS=4 (в варьированных прогонах — см. ниже).

## Разбор

1. Декод JPEG — доминирующая стоимость CPU (~10 мс/кадр): threads=1 ограничивает 6× на батчах.
2. threads=4→16 больше не улучшает: после ≈90 FPS узкое место смещается — чтение либо предобработка.
3. Для ≥100 FPS на слабом CPU ранее (прототип-драйвером, ближайшая к официальному реализации) — 120.7
   FPS при B32; в официальном скрипте не воспроизводится — резерв остался, чекаемым путь?
   EXTRACT_THREADS больше не добавляет (см. пункт 2).
4. Следующая станция — нетто A5000 + Xeon; латентность гарантированно проходит, throughput вероятно
   >100 при тех же дефолтных 4 потоках на 64 логических ядра.

Флаг качества EXTRACT_JPEG_DRAFT=1 не запускался: меняет векторы (dist-метрика 0.98, mAP 0.8638 raw),
по PR#5 решено оставить выкл — не включать.

Файлы: bench_extract_t{1,4,16}.json («threads» в describe()), run_t{1,4,16}.log.
Станца: native (официальный сценарий, без контейнера) — см. шапку.

## Docker-раздел (nvidia-container-toolkit установлен 18.10, sudo выдан)

После установки nvidia-container-toolkit и пересборки `case17-api:local` из glebmain e41f92a
(`docker compose build api`; pip-слои из кеша, финальная 247.6 с) официальный протокол прошёл
**в контейнере**, команда как в PR#5 §5:

```
docker run --rm --gpus all --network none -v <dataset>:/data:ro -v .../artifacts:/artifacts \
  case17-api:local python /srv/scripts/bench_extract.py --data /data --out /artifacts/bench_extract.json
```
