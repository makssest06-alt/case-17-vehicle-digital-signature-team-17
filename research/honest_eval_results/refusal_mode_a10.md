# Режим отказа: a10

Протокол «как сервис» (у запроса без пары в галерее остаётся кадр его машины с той же камеры), 5 фолдов по 150 машинам holdout, 25 % машин фолда без пары. Порог — максимум F1 при TNR ≥ 0.70 на фолде выбора по всем размерам сетки сразу, метрики — на остальных фолдах. Строгая точка — наименьший порог с TNR ≥ 0.98. Штраф: τ = 0.68127, top-100. Воспроизвести: `python research/refusal_mode.py --data-dir <данные> --env REID_WEIGHTS=<веса> --tag a10`.
