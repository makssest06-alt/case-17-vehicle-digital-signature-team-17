# Новый чистый студент против старого (пункт B)

## Что именно мерили

- В архиве `clean_student.zip` (распакован вне репозитория в
  `~/models/clean_student`) **нет `clean_student_a10_ep28.pt`**, который выбран в
  `research/CLEAN_RETRAIN_REPORT.md` (`6bf85da`). Есть `clean_student_a25_ep28.pt`
  (sha256 `b2f823ae…` — совпадает с `research/clean_student/manifest.json`),
  четыре чистых учителя (SigLIP 2 учитель там `ep30`, в манифесте `ep28`) и
  `clean_teacher_emb.npy`. **Ниже — a25; a10 будет промерен той же командой,
  как только появится файл.**
- Модель поднята кодом сервиса с окружением `.env.example` и
  `REID_WEIGHTS=<путь к весам>`: бэкбон из чекпоинта (`siglip2_base` →
  `vit_base_patch16_siglip_224`), 512D, `REID_TF_MODE=squash`, TTA выключен — как
  в манифесте. Источник кадров — готовые кропы `crops/` (как
  `make_submission.py`); по полным кадрам числа на ~0.005 выше
  (`honest_eval_summary.md`, сверка с командой).
- Варианты: `raw` — сырой косинус (так отвечает `/v1/search`); `rerank` —
  «k-reciprocal» из таблиц команды (поверх расширения запроса); `kr` —
  k-reciprocal без расширения запроса. Оба постобработанных — трансдуктивны, их
  параметры подобраны на этих же 150 машинах.
- Пороги: 0.8025 / 0.8465 — сервиса; 0.6699 / 0.8743 — из
  `CLEAN_RETRAIN_REPORT.md` (cross-camera / deployment, подобраны для α=10);
  «вне фолда» — `research/calibrate_refusal_folds.py`, режим без почти-дублей,
  порог свой для каждой модели.

### Что видно

- **a25 по сырому косинусу не лучше старого студента**: 8996 −0.008, 2.2k
  −0.011 (в пределах разброса фолдов ±0.09–0.10). Это согласуется с отчётом
  команды: у них a25 raw на 8996 0.5492 против 0.5567 у старого (по полным кадрам).
- **С k-reciprocal + расширением запроса a25 чуть лучше**: +0.004 на 8996,
  +0.020 на 2.2k (у команды +0.009 на 8996).
- **Почти весь прирост «k-reciprocal» даёт расширение запроса по ДРУГИМ
  запросам**: на 8996 raw 0.544 → kr 0.581 (+0.037) → rerank 0.721 (+0.177 к raw).
  Без расширения запроса k-reciprocal даёт +0.03–0.04. Сервис по одному кадру
  ни того, ни другого не получит.
- **Отказ у a25 немного лучше**: при recall ≈ 0.7 вне фолда TNR 0.680 против
  0.623, при recall ≈ 0.6 — 0.758 против 0.735; порог 0.8743 из отчёта даёт и
  a25 «recall < 15 %».
- Итог по a25: заметного выигрыша на честных галереях нет; выбранный командой
  α=10 (по их отчёту raw 8996 0.5585, +0.002 к старому) нужно промерить тем же
  протоколом — нужен файл `clean_student_a10_ep28.pt`.

Воспроизвести (новая модель — одна команда):

```bash
python research/honest_eval.py --data-dir <данные> --suite --postprocess raw,rerank,kr \
  --env REID_WEIGHTS=~/models/clean_student/clean_student_a25_ep28.pt --tag clean_a25
python research/calibrate_refusal_folds.py --data-dir <данные> --env REID_WEIGHTS=<веса> \
  --fixed "отчёт cross-camera=0.6699" --fixed "отчёт deployment=0.8743" \
  --out research/honest_eval_results/refusal_folds_clean_a25.json
```

Итог по всем галереям:

- **по сырому косинусу a25 лучше только на маленькой галерее** (+0.011 на

- **с k-reciprocal + расширением запроса a25 лучше на всех больших галереях**
  (+0.019 / +0.004 / +0.023), и выигрыш сохраняется без соседних кадров-запросов
  (2.2k, 1 запрос на камеру: +0.021);
- **recall отказа при том же пороге у a25 выше на 0.02–0.05 при почти том же TNR**;
- решения о замене студента эти числа не дают: для сервиса (сырой косинус)
  a25 не лучше; нужен a10.
