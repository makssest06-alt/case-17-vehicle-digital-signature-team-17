# Разбор ошибок по подгруппам (шаг 7)

Студент из `main` (`<repo>/weights/siglip2_distill_ensemble_ep28.pt`, `REID_TF_MODE=squash`, `EMBED_TTA_FLIP=0`), галерея 2.2k (машины holdout + весь тест), режим эталона, сырой косинус — как отвечает `/v1/search`; 5 фолдов вместе.
Запросов с парой 400, без пары 146 (в mAP не входят). mAP@10 0.7022, Rank-1 0.6775 — среднее по всем запросам вместе; среднее пяти фолдов в `honest_eval_student_rk_suite.md` — 0.704 / 0.678. По каждому фолду средний AP запросов сверен с `honest_eval.evaluate`. Ошибок top-1 — 129.

Воспроизвести: `python research/error_breakdown.py --data-dir <данные>`; картинки — `python research/error_examples.py --data-dir <данные>`.

## Как размечено

- Мелкий bbox — правило `research/error_analysis.py` (площадь рамки < 120 000 пикселей кадра; площадь берётся из `train.csv`, потому что кропы уменьшены до 512 px).
- Блики — глазами, на пару (машина, камера): засветка фар или солнца, сильное отражение на кузове; 38 пар из 361. Правило `error_analysis.py` «пикселей ярче 235 больше 2 %» отмечает 56 % запросов, в том числе солнечную плитку и белый кузов, поэтому только для сравнения.
- Ночь — глазами, на пару (машина, камера), по первому и последнему кадру: ночь 118 кадров, сумерки 32, разное в паре 9 пар. Правило `error_analysis.py` «яркость кропа < 70» здесь не годится: из 72 ночных запросов оно отметило 18, а ночью назвало 53 дневных кадра в тени (камеры с автоэкспозицией; яркость полного кадра тоже не разделяет: медиана 111 у ночи против 126 у дня).
- Ракурс — глазами по кропам, на пару (машина, камера): `vehicle_camera_labels.csv`, 361 пара (перед 132, зад 196, бок 20, разный ракурс в паре 5, не разобрать 8). Камеры парковочные, машины стоят в обе стороны, поэтому разметка по камере не годится. «Смена ракурса» — в галерее у запроса нет позитива того же ракурса. Повторный проход по всем 361 паре нашёл 1 ошибку (пара машины 314 с камеры 71: «перед» вместо «зад»), она исправлена.
- Цвет запроса — глазами, на машину: `vehicle_colors.csv`, 150 машин. Цвет по HSV кропа ошибался в 12 кадрах из 48, его не берём.
- Пары «запрос — неверный top-1» — глазами: `error_pairs_labels.csv`, все ошибки.
- Разметка — глазами модели (Claude) 17.10, один размечающий: это оценка, а не эталон. Второй проход тем же размечающим: ракурс — 1 ошибка из 361 пары, пары ошибок — 2 из 129 (две «соседние машины» оказались просто другой машиной), исправлены; ночь, блики и цвет — один проход. Правило `error_analysis.py` «похожая машина: сходство > 0.55» подобрано под шкалу CLIP-головы, у студента почти любой top-1 выше 0.55, поэтому не используется.
