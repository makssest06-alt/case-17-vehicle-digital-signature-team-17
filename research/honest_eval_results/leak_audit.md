# Аудит утечек и почти-дублей (шаг 1, D3/D4)

```bash
python research/audit_leaks.py --data-dir <папка с train.csv, test_*.csv, crops/> \
  --out-dir research/honest_eval_results
```

Полный отчёт — `leak_audit.json`, подозрительные пары — `leak_pairs.csv`.
Векторы — студент `siglip2_distill_ensemble_ep28.pt` (sha256 `500f7b47…`)
сервисным путём (`research/service_embeddings.py`, профиль `.env.example`).
Хэши — по кропам с запасом 10 % (`crops/`), 64 бита.

Данные: train 9556 кадров, 1541 машина, 96 камер; holdout

сдаточный тест — 1110 query, 750 gallery.

## 1. Утечки — всё, что должно быть нулём

| Проверка | Результат |
|---|---:|
| `val_ids.txt`, пересобранный `make_split.py`, совпадает с репозиторием | да |
| `vehicle_id` holdout ∩ обучение (1391 машина) | **0** |
| `image_id`: holdout query ∩ gallery · test query ∩ gallery · test ∩ train | **0 · 0 · 0** |
| Точные дубли файлов (sha256) — любые пары train + test | **0** |
| Почти-дубли кропов train ↔ test (pHash ≤ 4 **и** dHash ≤ 4) | **0** |
| Почти-дубли кропов holdout ↔ обучение (оба хэша ≤ 4) | **0** |
| Почти-дубли между **разными** машинами (оба хэша ≤ 4) | **1** — см. ниже |
| `research/audit_generalization.py` (Ростислав): failures / warnings | 0 / 0 |

**Студент не видел машин holdout как классов.** В чекпоинте нет списка строк
обучения (`args.rows_csv = D:\bm\improve_models\distill_train_rows.csv`), но
есть прототипы ArcFace `margin.weight` формы **(1391, 512)** = 1541 − 150.
`train_distill.py` нумерует классы как `sorted(vehicle_id)` строк обучения.
При нумерации «train без `val_ids.txt`» средний вектор **каждой** из 1391
машин попадает в свой прототип (**100 %**), и **ни один** прототип не ближе
к машине holdout. Косинус к ближайшему прототипу: свои машины — медиана
0.606, машины holdout — 0.404.

Чего эта проверка **не** доказывает: учитель (`args.teacher = teacher_emb.npy`)
и стартовый чекпоинт (`args.init_from = siglip2_init.pt`) могли видеть машины
holdout — их обучающих списков в репозитории нет. Косвенно против: косинус
кадров одной машины с разных камер у holdout в медиане 0.732, у обучающих
машин 0.847 (таблица ниже). Подтвердить может только тот, кто учил
`siglip2_init.pt` и учителя.

**Единственный межмашинный дубль.** Внутри train, не в holdout:
`aab87e0c…` (vid 1473) и `e2e37fe3…` (vid 1204) — dHash 0, pHash 2, оба с
камеры 90, рамки `486,451,753,440` и `480,451,759,440`, обе «машины» сняты
ровно камерами 43 и 90. На листе для просмотра — один и тот же серый
минивэн. Похоже на одну машину под двумя `vehicle_id`; на валидацию не
влияет, на обучение — один класс ArcFace разрезан на два.

Остальные 12 пар в `leak_pairs.csv` близки только по одному хэшу; глазами —
разные машины одной ливреи (каршеринг, такси) или одного ракурса.
Это не утечки, а трудные негативы — категория для разбора ошибок (шаг 7).

## 2. Почти-дубли одной машины — свойство данных, а не утечка

Кадров на пару (машина, камера): 1 — у 551 пары, 2 — у 994, **3 — у 2339**
(из 3884). Это соседние кадры одного проезда.

| Косинус студента | holdout (не учился) | обучение (учился) |
|---|---:|---:|
| та же машина, та же камера (медиана, p10) | **0.967**, 0.823 | 0.977, 0.888 |
| та же машина, другая камера (медиана, p10) | **0.732**, 0.514 | 0.847, 0.690 |
| разные машины (медиана) | −0.018 | −0.002 |

- Каждый из 551 query holdout имеет в gallery кадр **той же машины с той же
  камеры** (так строит сплит `make_split.py`). У **333 из 551 (60.4 %)** его
  косинус ≥ 0.95, медиана 0.967.
- Сдаточный тест устроен так же: у **60.3 %** тестовых query top-1 ≥ 0.95
  (п. 6 `main_audit.md`), а пар query ↔ gallery с обоими хэшами ≤ 4 — 189
  (у holdout на вдвое меньшем числе кадров — 132).

Следствие для метрик (проверено тестами `research/tests/test_honest_eval.py`):
- в mAP эталон такие кадры вычищает как junk, **но из присланных 10 позиций** —
  почти-дубль может занять место в top-10;
- в режиме отказа эталон junk не вычищает: почти-дубль даёт top-1 ≈ 0.97 и
  засчитывается как верный ответ. Порог 0.8025 откалиброван на таких
  позитивах (`refusal()` в `research/eval_service_path.py`, протокол
  `deployment` — галерея без фильтра камеры). Без почти-дублей верный
  кандидат — кадр с другой камеры; у пар «та же машина, другая камера»
  медиана косинуса 0.732, ниже порога. Сколько это даёт recall при пороге
  0.8025 (top-1 — максимум по галерее, он выше медианы пар) — измеряется в
  режиме `nodup` шага 3.
