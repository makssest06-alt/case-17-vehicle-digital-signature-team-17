# Кейс 17 · Цифровой признак транспортного средства

Прототип сервиса, который сопоставляет снимки одного автомобиля с разных камер
**без госномера**. Ветка `feat/prototype-skeleton` — работающий каркас: три
микросервиса, REST API, веб-интерфейс и генератор артефактов сдачи.

> Номера в датасете заблюрены. Использовать их остатки запрещено правилами кейса —
> решение, построенное на номере, снимается с оценки.

---

## Схема компонентов

```
                    браузер
                       │
                       ▼  :8080
        ┌──────────────────────────────┐
        │  web — nginx + одна страница │   рамка мышью, карточки кандидатов,
        │  /api/* → проксируется на api│   экспорт CSV/JSON
        └──────────────┬───────────────┘
                       │  внутренняя сеть case17net
                       ▼  :8000
        ┌──────────────────────────────┐
        │  api — FastAPI + uvicorn     │
        │                              │
        │  EmbeddingModel (интерфейс)  │  load() / embed_batch()
        │     └─ timm:resnet18 (CPU)   │  веса запечены в образ
        │                              │
        │  кадр + bbox → кроп +10%     │
        │      → вектор 512D (L2)      │
        └──────────────┬───────────────┘
                       │
                       ▼  :5432 (наружу не публикуется)
        ┌──────────────────────────────┐
        │  db — postgres 16 + pgvector │
        │  gallery(id, vehicle_id,     │
        │    image_path, bbox,         │
        │    embedding vector(512),    │
        │    created_at)               │
        │  HNSW по косинусу            │
        └──────────────────────────────┘
```

Данные (кропы) монтируются в api только на чтение из `/opt/case17/data`.
Артефакты сдачи пишутся в `./artifacts`.

## Запуск одной командой

```bash
cp .env.example .env      # и поменяй POSTGRES_PASSWORD
docker compose up -d
```

Дальше:

- интерфейс — http://localhost:8080
- Swagger — http://localhost:8000/docs
- состояние — `docker compose ps`

Снаружи порты сейчас закрыты security group облака, поэтому с ноутбука удобнее
через туннель:

```bash
ssh -L 8080:localhost:8080 -L 8000:localhost:8000 lct
```

### Смена модели

Модель спрятана за интерфейсом `EmbeddingModel` (`api/app/models/base.py`).
Чтобы поставить другую — достаточно поменять `EMBED_MODEL` в `.env` и пересобрать:

```bash
EMBED_MODEL=resnet50 docker compose build api
docker compose down -v && docker compose up -d   # -v обязателен: меняется размерность вектора
```

Когда появится своя обученная ReID-модель, в `api/app/models/registry.py`
добавляется ветка `reid:v1 → ReidCheckpointModel(...)`, и конфиг переключается
одной строкой. Веса кладём в `/opt/case17/models`.

## API

Все ответы — JSON. Ошибки входных данных возвращают 422 с человекочитаемым `detail`.

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/v1/embed` | кадр + bbox → вектор признака |
| POST | `/v1/gallery` | добавить ТС в галерею известных |
| POST | `/v1/gallery/bulk-import` | массовый импорт папки кропов по csv |
| POST | `/v1/search` | найти кандидатов или вернуть отказ |
| GET | `/v1/gallery` | что лежит в галерее (`limit`, `offset`) |
| DELETE | `/v1/gallery/{id}` | удалить запись |
| GET | `/health` | жив ли процесс (базу не трогает) |
| GET | `/ready` | модель загружена и база отвечает |

### Поиск

```bash
curl -X POST http://localhost:8000/v1/search \
  -F "image=@frame.jpg" -F "x=651" -F "y=385" -F "w=781" -F "h=600" \
  -F "top_n=10" -F "threshold=0.75"
```

Успех:

```json
{"refusal": false, "threshold": 0.75, "top_n": 10, "model": "timm:resnet18",
 "took_ms": 77.1,
 "candidates": [{"id": 11, "vehicle_id": null, "image_path": "...",
                 "bbox": [1202,265,588,482], "confidence": 0.9776}]}
```

Отказ — это штатный ответ, а не ошибка:

```json
{"refusal": true, "reason": "low_similarity",
 "message": "Уверенного совпадения нет: лучший кандидат 0.612 при пороге 0.750.",
 "candidates": []}
```

Причины отказа: `gallery_empty` (сравнивать не с чем), `low_similarity`
(лучший кандидат ниже порога).

### Массовый импорт

```bash
curl -X POST http://localhost:8000/v1/gallery/bulk-import \
  -H "Content-Type: application/json" \
  -d '{"images_dir":"/data/crops/gallery","csv_path":"/data/crops/crops_gallery.csv",
       "already_cropped":true,"truncate":true}'
```

Пути обязаны лежать внутри `DATA_DIR` — наружу файловой системы сервис не выпускает.

### Валидация входа

- формат: JPEG, PNG, WEBP, BMP; всё остальное — 422 с объяснением;
- размер: лимит `MAX_UPLOAD_MB` (по умолчанию 20 МБ);
- bbox: целые, `w > 0`, `h > 0`, не отрицательные координаты, не выходит за кадр;
- защита от decompression bomb (лимит по числу пикселей);
- `top_n` 1..100, `threshold` 0..1.

## Артефакты сдачи

```bash
docker compose exec api python scripts/make_submission.py
```

Кладёт в `artifacts/` ровно то, что требует README датасета:

| Файл | Что внутри |
|---|---|
| `submission.csv` | `query_id,gallery_id_1..gallery_id_10` — топ-10 по убыванию близости |
| `embeddings.npy` | float32 `(1110 + 750, 512)`: сначала все query в порядке `test_query.csv`, затем все gallery в порядке `test_gallery.csv` |
| `candidates.csv` | `query_id,gallery_id,confidence` — только принятые; если для query ничего не прошло порог, строк нет (отказ) |

Эти три файла намеренно **не** попадают под `.gitignore` — они должны лежать в репозитории.

## Ограничения текущей версии

**Модель — заглушка.** `resnet18`, обученный на ImageNet, никогда не учился
различать конкретные автомобили. Он даёт похожесть «по картинке вообще», поэтому
косинус между любыми двумя кропами высокий (0.83–0.98), и порог 0.75 при такой
модели почти ничего не отсекает: из 1110 query отказ сработал ровно на одном.

Это ожидаемо и нормально для каркаса: цель ветки — рабочий контур от загрузки
кадра до артефактов сдачи. Реальные числа появятся, когда в `/opt/case17/models`
ляжет ReID-модель, обученная на GPU, а порог будет откалиброван по
cross-camera валидации (см. `VALIDATION_PROTOCOL.md` в ветке команды).

## Конфигурация

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `EMBED_MODEL` | `resnet18` | бэкбон timm |
| `EMBED_DIM` | `512` | размерность вектора в базе |
| `INPUT_SIZE` | `224` | сторона входа модели |
| `SEARCH_TOP_N` | `10` | кандидатов по умолчанию |
| `SEARCH_THRESHOLD` | `0.75` | порог отказа |
| `MAX_UPLOAD_MB` | `20` | лимит загружаемого файла |
| `BBOX_PAD` | `0.10` | запас вокруг bbox, как у кропов в `/opt/case17/data` |

Секреты только в `.env`, который в git не попадает.
