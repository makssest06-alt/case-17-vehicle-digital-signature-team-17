## 3. Особенности BBox и объектов
- Средний размер BBox: ширина 689 px, высота 500 px (автомобили занимают крупную часть кадра — примерно 35-40% площади кадра).
- Минимальный размер BBox: ~150x150 px.
- Максимальный размер BBox: ~1740x1050 px.
- Средний aspect ratio: ~1.38 (соотношение сторон типичного легкового/грузового авто).
- Оптимальный входной размер для нейросети: **256x256** или **384x288 / 256x192** (с сохранением соотношения сторон через letterboxing/padding).

## 4. Особенности Test Query & Gallery
- 	est_query.csv содержит 1 110 запросов.
- 	est_gallery.csv содержит 750 кандидатов в галерее.
- Число запросов (1110) превышает число объектов в галерее (750). Само по себе это **не доказывает** наличие negative queries: один автомобиль может иметь несколько query-изображений, а несколько автомобилей могут иметь разное число наблюдений.
- Официальные labels test не выданы. Поэтому нельзя вычислить test F1/TNR или заранее утверждать долю отказов. Для разработки создаём контролируемую open-set validation из train и отдельно описываем это ограничение в README.
- Режим refusal всё равно является обязательным артефактом: candidates.csv должен содержать accepted candidates с confidence либо пустой результат.
